# לטיפול — The Unresolved Register Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/inbox` — one destination holding every decision the platform refused to make on its own — and delete `/data`, the page that read three workbooks off disk on every request and never noticed a confirmed block.

**Architecture:** One discriminated union, `InboxItem`, covers all seven kinds of open item. `inboxItems(db, input)` assembles it from queries that already exist (`worklist`, `collisionGroups`, `sheetsNeedingSeason`, `flaggedArithmetic`, `listUnlinkedNames`, `unnamedObligations`) plus three new library modules: the evidence reader, the suggestion builder, and the item assembler itself. The page is a Server Component; selection, tab and kind filter all live in the URL (R6), so the rail is links and the only client components are the keyboard binder, the action bar and the toast. Every action maps to a server action, and every refusal message already written in Hebrew under `src/lib/import/promote/` is reused verbatim rather than re-worded.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Drizzle ORM, Postgres (PGlite in tests), CSS Modules, Vitest, @testing-library/react.

**Spec:** `docs/superpowers/specs/2026-09-17-ui-redesign-design.md` (D2; also B2, E2, E6, R1, R6, R7, R8, R9, R10, R11, R12). It implements the register of `docs/superpowers/specs/2026-09-15-block-promotion-and-data-view-design.md` (W16–W24), whose seven `/data` sections this screen absorbs.

## Global Constraints

Every task's requirements implicitly include this section.

- **No new runtime dependencies (R1).** No component library, no CSS framework, no icon package, no date library, no keyboard library. Everything here is hand-written.
- **No schema change, no promoter change, no classifier change.** The spec's "it is the surface, and only the surface" is binding. Where a figure is missing, this plan adds a query function in `src/lib` and says what it returns; it never moves a rule out of `src/lib` into a component. Two consequences are ruled on explicitly in Tasks 3 and 4, because both would otherwise reach for a column.
- **Server Components by default (R7).** A client component carries a comment on its first line saying why it must be one.
- **A drawer is a URL (R6).** The open item is `?item=<id>`, the tab is `?tab=decide|notice|done`, the kind filter is `?kind=<group>`. No client state holds anything a lead might want to send to someone else.
- **Keyboard shortcuts bind `event.code`, never `event.key` (R10).** With a Hebrew layout `event.key` for `Z` is `ז`. Digits are `Digit1`–`Digit5`; rail movement is `ArrowUp`/`ArrowDown`.
- **Hebrew RTL throughout.** CSS logical properties only — `padding-inline`, `inset-inline-start`, `text-align: start`. Never `left`/`right`, with A10's single exception for a numeric column. Latin, numeric and mixed-direction runs go in `<bdi>`.
- **Hebrew copy is reused verbatim (E5, R9).** Every refusal message in `src/lib/import/promote/*.ts` — `'שורת סה״כ היא סכום מחושב, לא תנועה'`, `'לגיליון לא נקבעה עונה, ותקציב חייב עונה'`, `MESSAGES.sheet.undecided`, and the rest — is rendered as stored. No English reaches the screen; an unmapped server error renders the generic Hebrew fallback and is logged.
- **Money is `numeric(12,2)` in Postgres and integer agorot in JS.** `src/lib/money.ts` is the only converter. No float arithmetic on money.
- **Blankness uses `isBlank` from `@/lib/text/normalize`, never `.trim()`.**
- **`@/db` must never enter the module graph of a `'use server'` file's callees or of a test.** Domain modules under `@/lib` take `db: AnyDb` (from `@/lib/db-types`) as their first parameter.
- **Admin-only.** Every page and every server action calls `requireAdmin()` from `@/lib/auth/guard` and throws or returns `{ ok: false, error: 'אין הרשאה' }` on failure. `src/app/admin-guard.test.ts` is a static net over every `page.tsx` and `actions.ts` under `src/app/(admin)`; new files must satisfy it.
- **No page reads a file from disk at request time (E6).** Enforced by a source-scan test, not by discipline.
- **Never run `npm install`.** It drops the rolldown native binding. If you hit `Cannot find module @rolldown/binding-darwin-arm64`, repair with `npm install --no-save @rolldown/binding-darwin-arm64@1.2.8`.
- **`@testing-library/user-event` is NOT installed.** Use `fireEvent`.
- **`vi.mock` factories are hoisted above every other statement.** A factory referencing a plain top-level `const` throws `ReferenceError`; use `vi.hoisted`.
- **Component tests carry `/** @vitest-environment jsdom */` as the file's first comment.** Database tests use `createTestDb()` from `@/test/db`.
- **Commit with `git commit -F - <<'MSG'`.** `git commit -m` performs command substitution on backticked spans in this zsh and silently deletes them. Every commit message ends with `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`.
- **`docs/reference-data/` holds real names and amounts, is read-only, and must never be modified.**

### Rulings (binding, and settled here so no task re-opens them)

- **Ruling 1 — `blocking` means the system is holding a fact back until a person decides.** It is the single flag on every item. `blocking` → the item is in ממתין להחלטה and the badge counts it; `!blocking` → לידיעה, and the badge never counts it. There is no separate `tab` field: the tab is derived, so the two can never disagree.
- **Ruling 2 — bulk promotion is gated by a narrower predicate, `blocksPromotion(item)`.** True only for `sheet-collision`, `block-undecided`, and `sheet-season` when a `no-season` refusal actually exists behind it — the three cases where `promoteAll` itself refuses or skips. It is deliberately *not* every blocking item: unlinked names and unnamed debts are *produced by* promotion, so gating promotion on them deadlocks — the only way to clear the name queue is to promote, and a new upload could never be promoted while one name sat in it. This is exactly the Wave 2 ruling ("disabled while any decision is open", where the decisions are section 1's sheets and collisions), stated as a function.
- **Ruling 3 — a refused row is information, not a decision.** Every `refused-row` item and every `arithmetic-flag` item is `blocking: false`. W20 already says arithmetic flags are "flagged, never blocked"; a `total-row` or `carry-forward` refusal is the promoter doing its job correctly, and a register that asks a lead to decide about it is asking them to overrule a rule they want. The only action on such an item is a link to the cell.
- **Ruling 4 — a refusal whose reason is already carried by another item kind is not emitted twice.** Dropped from `refused-row`: `no-season`, `sheet-undecided`, `sheet-ambiguous`, `sheet-superseded`, `unconfirmed`, `unmapped-column`. Also dropped entirely: `blank-row` — a blank row is the absence of a fact, not a fact anyone needs told about, and leaving it in buries לידיעה under dozens of rows.
- **Ruling 5 — confidence is a word, never a number.** `חזקה`, `אפשרית`, `חלשה`. No percentage is rendered, and none is stored on the suggestion. A percentage invites "80% is close enough", which is the guess this platform has refused since `resolveName`.
- **Ruling 6 — evidence comes from `blocks.raw_grid` and from nowhere else (E6, W16, W22).** Not from `docs/reference-data`, not from the blob store, not from a re-parse. A source-scan test in Task 1 and another in Task 8 hold the line.
- **Ruling 7 — the inbox is camp-wide and says so on screen (R5).** A name, a sheet, a duplicate copy and a nameless debt do not belong to a season, so `inboxItems` takes no `seasonId`. `flaggedArithmetic` already spans seasons and each of its items names its own.
- **Ruling 8 — a snooze is personal and a cookie; an ignore is the camp's and is stored.** See Tasks 3 and 4 for why each lands where it does, and what each says on screen about its own scope.

  ```ts
  export interface EvidenceCell {
    /** The cell exactly as stored in `raw_grid`. */
    text: string;
    /** `B` — the sheet column letter, from the block's `left` offset. */
    column: string;
    /** True on the one cell this decision is about. */
    marked: boolean;
  }

  export interface EvidenceRow {
    /** Absolute 1-indexed sheet row. */
    sheetRow: number;
    /** 1-indexed position of the row inside the block's stored grid. */
    blockRow: number;
    cells: EvidenceCell[];
    /** True on the row the decision is about. */
    marked: boolean;
  }

  export interface Evidence {
    blockId: string;
    sheetName: string;
    filename: string;
    /** `דמי קאמפ!B14`, or `דמי קאמפ!14` when no column was named. */
    reference: string;
    /** Column letters across the block, `left` to `right`. */
    columns: string[];
    rows: EvidenceRow[];
    /** Rows above and below that were not returned. */
    hiddenBefore: number;
    hiddenAfter: number;
  }

  /**
   * The workbook rows around one cell, read from `blocks.raw_grid`.
   *
   * `sheetRow` is absolute — the same number `source_row` stores — so a block
   * whose bounds are re-detected still points at the cell a lead can open.
   * `column` is an absolute sheet column, 1-indexed, matching
   * `ColumnMapping.column`; `null` marks the whole row instead.
   */
  export async function blockEvidence(
    db: AnyDb,
    blockId: string,
    sheetRow: number,
    opts?: { column?: number | null; radius?: number },
  ): Promise<Evidence | null>;

  export interface CopyDiffRow {
    label: string;
    /** One entry per sheet id given, in the order given. `null` means that
     *  copy has no such line at all. */
    values: Array<string | null>;
    differs: boolean;
  }

  export type CopyDiff =
    | { ok: true; rows: CopyDiffRow[]; differing: number }
    /** Hebrew, shown in place of a comparison that cannot be made honestly. */
    | { ok: false; reason: string };

  /**
   * Line-by-line comparison of two or more copies of the same sheet (W19).
   *
   * Reads each copy's confirmed column mapping to find the label and total
   * columns. A copy with no mapping cannot be compared without guessing which
   * column is which, so the whole comparison refuses rather than inventing one.
   */
  export async function copyDiff(db: AnyDb, sheetIds: string[]): Promise<CopyDiff>;
  ```

**Ruling (binding):** the label and total columns come from `block_mappings.column_map` — the same mapping the promoter reads — and never from a positional guess such as "first column is the label, last numeric column is the total". `budget_lines` uses `item`/`total`, `ledger` uses `description`/`outflow`, `ticket_rounds` uses `round`/`total`, `obligations` uses `description`/`amount`. A sheet whose blocks carry no mapping for its archetype returns `{ ok: false, reason: 'אי אפשר להשוות בין העותקים עד שיאושר שיוך עמודות לשני הצדדים' }`.

```ts
  columns: string[]; rows: EvidenceRow[]; hiddenBefore: number; hiddenAfter: number;
}

const DEFAULT_RADIUS = 2;

/**
 * The workbook rows around one cell, read from `blocks.raw_grid` and from
 * nothing else. The page this feeds used to parse three workbooks off disk on
 * every request; E6 and W16 exist because of it.
 *
 * `sheetRow` is absolute, the same number `source_row` stores, so a
 * re-detected block still points at the cell a lead can open. `column` is an
 * absolute sheet column matching `ColumnMapping.column`; the index into a
 * stored row is `column - block.left`.
 */
export async function blockEvidence(
  db: AnyDb,
  blockId: string,
  sheetRow: number,
  opts: { column?: number | null; radius?: number } = {},
): Promise<Evidence | null> {
  const [row] = await db
    .select({
      id: blocks.id, top: blocks.top, left: blocks.left, right: blocks.right,
      rawGrid: blocks.rawGrid, sheetName: sheets.name, filename: uploads.filename,
    })
    .from(blocks)
    .innerJoin(sheets, eq(sheets.id, blocks.sheetId))
    .innerJoin(uploads, eq(uploads.id, sheets.uploadId))
    .where(eq(blocks.id, blockId));
  if (!row) return null;

  const index = sheetRow - row.top;
  if (index < 0 || index >= row.rawGrid.length) return null;

  const radius = opts.radius ?? DEFAULT_RADIUS;
  const from = Math.max(0, index - radius);
  const to = Math.min(row.rawGrid.length - 1, index + radius);

  const width = Math.max(1, row.right - row.left + 1);
  const columns = Array.from({ length: width }, (_, i) => colLabel(row.left + i));

  const markedColumn = opts.column ?? null;
  const markedIndex = markedColumn === null ? null : markedColumn - row.left;

  const rows: EvidenceRow[] = [];
  for (let i = from; i <= to; i += 1) {
    const raw = row.rawGrid[i] ?? [];
    const isMarkedRow = i === index;
    rows.push({
      sheetRow: row.top + i,
      blockRow: i + 1,
      marked: isMarkedRow,
      cells: columns.map((column, c) => ({
        column,
        text: raw[c] ?? '',
        marked: isMarkedRow && markedIndex === c,
      })),
    });
  }

  const reference = markedColumn === null
    ? `${row.sheetName}!${sheetRow}`
    : `${row.sheetName}!${colLabel(markedColumn)}${sheetRow}`;

  return {
    blockId: row.id,
    sheetName: row.sheetName,
    filename: row.filename,
    reference,
    columns,
    rows,
    hiddenBefore: from,
    hiddenAfter: row.rawGrid.length - 1 - to,
  };
}
```

```ts
export interface CopyDiffRow {
  label: string; values: Array<string | null>; differs: boolean;
}
export type CopyDiff =
  | { ok: true; rows: CopyDiffRow[]; differing: number }
  | { ok: false; reason: string };

/** The label and value fields each archetype's column map calls its own. */
const COMPARED_FIELDS: Partial<Record<BlockArchetype, { label: string; value: string }>> = {
  budget_lines: { label: 'item', value: 'total' },
  ledger: { label: 'description', value: 'outflow' },
  ticket_rounds: { label: 'round', value: 'total' },
  obligations: { label: 'description', value: 'amount' },
};

const NO_MAPPING = 'אי אפשר להשוות בין העותקים עד שיאושר שיוך עמודות לשני הצדדים';

/**
 * Line-by-line comparison of the copies of one sheet (W19), so a lead choosing
 * which copy is authoritative sees what the choice costs.
 *
 * The label and value columns come from the stored column map, never from a
 * positional guess: "the first column is the label" is exactly the kind of
 * inference the promoter refuses, and a comparison built on it would show a
 * lead a difference that is not there.
 */
export async function copyDiff(db: AnyDb, sheetIds: string[]): Promise<CopyDiff> {
  if (sheetIds.length < 2) return { ok: false, reason: NO_MAPPING };

  const rows = await db
    .select({
      sheetId: blocks.sheetId, left: blocks.left, top: blocks.top,
      headerRow: blocks.headerRow, archetype: blocks.archetype,
      rawGrid: blocks.rawGrid, columnMap: blockMappings.columnMap,
    })
    .from(blocks)
    .leftJoin(blockMappings, eq(blockMappings.blockId, blocks.id))
    .where(inArray(blocks.sheetId, sheetIds));

  const perSheet = new Map<string, Map<string, string>>();
  const labelOrder: string[] = [];
  const seen = new Set<string>();

  for (const sheetId of sheetIds) perSheet.set(sheetId, new Map());

  for (const block of rows) {
    const fields = COMPARED_FIELDS[block.archetype];
    if (!fields) continue;
    if (!block.columnMap) return { ok: false, reason: NO_MAPPING };

    const labelCol = block.columnMap.find((m) => m.field === fields.label);
    const valueCol = block.columnMap.find((m) => m.field === fields.value);
    if (!labelCol || !valueCol) return { ok: false, reason: NO_MAPPING };

    const into = perSheet.get(block.sheetId)!;
    for (let i = 0; i < block.rawGrid.length; i += 1) {
      const sheetRow = block.top + i;
      if (block.headerRow !== null && sheetRow <= block.headerRow) continue;
      const raw = block.rawGrid[i] ?? [];
      const label = raw[labelCol.column - block.left] ?? '';
      if (isBlank(label)) continue;
      const key = normalizeHebrew(label);
      if (!seen.has(key)) { seen.add(key); labelOrder.push(label); }
      into.set(key, raw[valueCol.column - block.left] ?? '');
    }
  }

  for (const sheetId of sheetIds) {
    if (perSheet.get(sheetId)!.size === 0) return { ok: false, reason: NO_MAPPING };
  }

  const diff: CopyDiffRow[] = labelOrder.map((label) => {
    const key = normalizeHebrew(label);
    const values = sheetIds.map((id) => perSheet.get(id)!.get(key) ?? null);
    const first = values[0];
    return { label, values, differs: values.some((v) => v !== first) };
  });

  return { ok: true, rows: diff, differing: diff.filter((r) => r.differs).length };
}
```

**Rulings (binding):**

1. **`suggestPeopleForName` never decides.** It orders and explains; `resolveName`'s refusal to pick between candidates stands untouched. Nothing in this module writes.
2. **The confidence word is derived from the reasons, by rule, and is not a rounded score.**
   - `חזקה` — the candidate matched exactly **and** is the only exact match. This is precisely the condition under which `resolveName` sets `personId`, so the strongest word on screen means the same thing the library means.
   - `אפשרית` — not the sole exact match, and the candidate carries `in-season-roster`.
   - `חלשה` — everything else.
3. **The list is capped at three** (`limit`, default 3) so the digit map in Task 5 stays stable: candidates take digits 1–3, and everything beyond is reached through `חיפוש אדם אחר`.
4. **`not-in-season-roster` is a reason, and it is shown.** A reason against is evidence too, and hiding it is how a lead links a payment to the wrong person.

```ts
import { and, eq } from 'drizzle-orm';
import type { AnyDb } from '@/lib/db-types';
import {
  persons, personAliases, memberships, seasons, dues, payments,
} from '@/db/schema/camp';
import { normalizeHebrew } from '@/lib/text/normalize';
import { toAgorot, formatILS } from '@/lib/money';
import { resolveName } from './identity';

export type MatchConfidence = 'חזקה' | 'אפשרית' | 'חלשה';

export type MatchReasonKey =
  | 'exact-normalized' | 'alias-prefix' | 'same-first-name' | 'surname-initial'
  | 'in-season-roster' | 'not-in-season-roster' | 'paid-same-amount-same-day';

export interface MatchReason { key: MatchReasonKey; label: string }

export interface NameSuggestion {
  personId: string; displayName: string; alias: string;
  reasons: MatchReason[]; confidence: MatchConfidence;
}

export interface NameEvidence {
  amountAgorot?: number | null;
  onDate?: Date | null;
}

const DEFAULT_LIMIT = 3;

/** A surname initial: one letter, optionally followed by a geresh or a dot. */
const INITIAL = /^[֐-׿]['׳.]?$/;

function tokens(text: string): string[] {
  return normalizeHebrew(text).split(' ').filter((part) => part.length > 0);
}

function sameDay(a: Date, b: Date): boolean {
  return a.getUTCFullYear() === b.getUTCFullYear()
    && a.getUTCMonth() === b.getUTCMonth()
    && a.getUTCDate() === b.getUTCDate();
}

/**
 * Ordered candidates for one unattributed name, each carrying the reasons
 * behind it and a confidence word.
 *
 * It explains; it never decides. `resolveName` stays the only thing that says
 * "this is the person", and it only says so for a sole exact match — which is
 * exactly the condition that earns the word חזקה here, so the strongest word a
 * lead sees means the same thing the library means.
 *
 * The confidence is a word because a percentage invites "80% is close enough".
 * Merging two people's dues, debts and ownerships is not reversible from the
 * UI, and a number on this screen would be an invitation to guess (Ruling 5).
 */
export async function suggestPeopleForName(
  db: AnyDb,
  rawName: string,
  opts: { seasonId?: string | null; evidence?: NameEvidence; limit?: number } = {},
): Promise<NameSuggestion[]> {
  const resolution = await resolveName(db, rawName);
  if (resolution.candidates.length === 0) return [];

  const queryTokens = tokens(rawName);
  const exactCount = resolution.candidates.filter((c) => c.exact).length;

  const seasonId = opts.seasonId ?? null;
  const seasonName = seasonId === null ? null : (await db
    .select({ name: seasons.name }).from(seasons).where(eq(seasons.id, seasonId)))[0]?.name ?? null;

  const roster = new Set<string>();
  if (seasonId !== null) {
    const rows = await db.select({ personId: memberships.personId })
      .from(memberships).where(eq(memberships.seasonId, seasonId));
    for (const row of rows) roster.add(row.personId);
  }

  const evidence = opts.evidence;
  const paidSameDay = new Set<string>();
  if (evidence?.amountAgorot != null && evidence.onDate != null) {
    const rows = await db
      .select({ personId: dues.personId, amount: payments.amount, paidOn: payments.paidOn })
      .from(payments)
      .innerJoin(dues, eq(dues.id, payments.dueId));
    for (const row of rows) {
      if (toAgorot(row.amount) !== evidence.amountAgorot) continue;
      if (!sameDay(row.paidOn, evidence.onDate)) continue;
      paidSameDay.add(row.personId);
    }
  }

  const suggestions: NameSuggestion[] = resolution.candidates.map((candidate) => {
    const reasons: MatchReason[] = [];
    const aliasTokens = tokens(candidate.alias);

    if (candidate.exact) {
      reasons.push({ key: 'exact-normalized', label: 'איות זהה' });
    } else {
      reasons.push({ key: 'alias-prefix', label: 'השם הוא תחילית של הכינוי השמור' });
    }

    if (!candidate.exact && queryTokens[0] && queryTokens[0] === aliasTokens[0]) {
      reasons.push({ key: 'same-first-name', label: 'שם פרטי זהה' });
    }

    const last = queryTokens.at(-1);
    const aliasLast = aliasTokens.at(-1);
    if (
      queryTokens.length > 1 && aliasTokens.length > 1
      && last && aliasLast && INITIAL.test(last) && last[0] === aliasLast[0]
    ) {
      reasons.push({ key: 'surname-initial', label: 'האות הראשונה של שם המשפחה' });
    }

    if (seasonName !== null) {
      reasons.push(roster.has(candidate.personId)
        ? { key: 'in-season-roster', label: `ברשימת ${seasonName}` }
        : { key: 'not-in-season-roster', label: `לא ברשימת ${seasonName}` });
    }

    if (paidSameDay.has(candidate.personId) && evidence?.amountAgorot != null) {
      reasons.push({
        key: 'paid-same-amount-same-day',
        label: `שילם/ה ${formatILS(evidence.amountAgorot)} באותו תאריך`,
      });
    }

    const inRoster = reasons.some((r) => r.key === 'in-season-roster');
    let confidence: MatchConfidence;
    if (candidate.exact && exactCount === 1) confidence = 'חזקה';
    else if (inRoster) confidence = 'אפשרית';
    else confidence = 'חלשה';

    return {
      personId: candidate.personId,
      displayName: candidate.displayName,
      alias: candidate.alias,
      reasons,
      confidence,
    };
  });

  const rank: Record<MatchConfidence, number> = { 'חזקה': 0, 'אפשרית': 1, 'חלשה': 2 };
  suggestions.sort((a, b) => (
    rank[a.confidence] - rank[b.confidence] || b.reasons.length - a.reasons.length
  ));

  return suggestions.slice(0, opts.limit ?? DEFAULT_LIMIT);
}
```

```ts
  aliasId: string;
  alias: string;
  normalized: string;
  source: string;

  aliasId: personAliases.id,
  alias: personAliases.alias,
  normalized: personAliases.normalized,
  source: personAliases.source,
  ignoredBy: personAliases.confirmedBy,
  ignoredAt: personAliases.confirmedAt,
};

/**
 * Names still waiting for a decision.
 *
 * An alias with no person and a `confirmed_by` is not waiting: someone looked
 * at it and said it is not a person. That pair of columns is the whole storage
 * for the ignore state — every existing writer sets `person_id` whenever it
 * stamps `confirmed_by`, and `unlinkAlias` clears the two together, so the
 * combination is unreachable by anything else and needs no new column.
 * `identity.test.ts` pins that invariant.
 */
export async function listUnlinkedNames(db: AnyDb): Promise<UnlinkedName[]> {
  return db.select(UNLINKED_COLUMNS).from(personAliases)
    .where(and(isNull(personAliases.personId), isNull(personAliases.confirmedBy)))
    .orderBy(asc(personAliases.normalized));
}

export async function listIgnoredNames(db: AnyDb): Promise<UnlinkedName[]> {
  return db.select(UNLINKED_COLUMNS).from(personAliases)
    .where(and(isNull(personAliases.personId), isNotNull(personAliases.confirmedBy)))
    .orderBy(asc(personAliases.normalized));
}

 * header the block detector swept in.
 *
 * Camp-wide and attributed, unlike a snooze: the next lead should not be asked
 * the same question, and the decision names who made it. Reversible through
 * `unignoreName`, which is why the toast on this action offers undo.
 */
export async function ignoreName(db: AnyDb, aliasId: string, email: string): Promise<void> {
  const [alias] = await db.select({ personId: personAliases.personId })
    .from(personAliases).where(eq(personAliases.id, aliasId));
  if (!alias) throw new Error(`unknown alias ${aliasId}`);
  if (alias.personId !== null) {
    throw new Error('כינוי שמשויך לאדם — יש לנתק אותו לפני שמסמנים אותו כלא-אדם');
  }
  await db.update(personAliases)
    .set({ confirmedBy: email, confirmedAt: new Date() })
    .where(eq(personAliases.id, aliasId));
}

/** Returns an ignored name to the queue, clearing the decision with it. */
export async function unignoreName(db: AnyDb, aliasId: string): Promise<void> {
  await db.update(personAliases)
    .set({ confirmedBy: null, confirmedAt: null })
    .where(eq(personAliases.id, aliasId));
}
```

```ts
}
```

```ts
import { cookies } from 'next/headers';

export const SNOOZE_COOKIE = 'inbox_snooze';
export const SNOOZE_LIMIT = 50;
export const SNOOZE_DAYS = 7;
const DAY_MS = 86_400_000;

/**
 * Deferrals live in a server-readable cookie rather than a table.
 *
 * This phase changes no schema, and a cookie is already how this codebase
 * carries per-viewer state the server must see on the first paint (the theme,
 * A13). The cost is real and is stated on screen: a snooze is this browser's,
 * not the camp's, so the item reads נדחה על ידך עד … rather than נדחה.
 */
export function parseSnoozes(raw: string | undefined, now: Date): Map<string, Date> {
  const out = new Map<string, Date>();
  if (!raw) return out;

  let parsed: unknown;
  try {
    parsed = JSON.parse(raw);
  } catch {
    return out;
  }
  if (typeof parsed !== 'object' || parsed === null || Array.isArray(parsed)) return out;

  for (const [id, value] of Object.entries(parsed as Record<string, unknown>)) {
    if (typeof value !== 'string') continue;
    const until = new Date(value);
    if (Number.isNaN(until.getTime())) continue;
    if (until.getTime() <= now.getTime()) continue;
    out.set(id, until);
  }
  return out;
}

export function serializeSnoozes(snoozes: ReadonlyMap<string, Date>): string {
  const kept = [...snoozes.entries()]
    .sort((a, b) => a[1].getTime() - b[1].getTime())
    .slice(0, SNOOZE_LIMIT);
  return JSON.stringify(Object.fromEntries(
    kept.map(([id, until]) => [id, until.toISOString()]),
  ));
}

export async function readSnoozes(now: Date): Promise<Map<string, Date>> {
  const store = await cookies();
  return parseSnoozes(store.get(SNOOZE_COOKIE)?.value, now);
}

async function write(snoozes: ReadonlyMap<string, Date>): Promise<void> {
  const store = await cookies();
  store.set(SNOOZE_COOKIE, serializeSnoozes(snoozes), {
    httpOnly: true,
    sameSite: 'lax',
    path: '/',
    maxAge: 60 * 60 * 24 * 90,
  });
}

export async function snoozeItem(
  itemId: string, now: Date, days: number = SNOOZE_DAYS,
): Promise<Date> {
  const snoozes = await readSnoozes(now);
  const until = new Date(now.getTime() + days * DAY_MS);
  snoozes.set(itemId, until);
  await write(snoozes);
  return until;
}

export async function unsnoozeItem(itemId: string): Promise<void> {
  const snoozes = await readSnoozes(new Date(0));
  snoozes.delete(itemId);
  await write(snoozes);
}
```

**Rulings (binding):**

1. **`blocking` is one flag and the tab is derived from it.** `tabOf` is `item.blocking ? 'decide' : 'notice'`. There is no stored tab, so the badge and the tab strip cannot disagree.
2. **A snoozed item is never blocking.** `snoozedUntil !== null` forces `blocking: false`, which moves it to לידיעה and takes it out of the badge. That is the whole point of a deferral.
3. **`blocking` by kind:** `unlinked-name` yes; `sheet-season` yes; `sheet-collision` yes; `block-undecided` yes; `unnamed-debt` yes; `refused-row` no; `arithmetic-flag` no.
4. **Ruling 4's drop list is implemented here.** Refusals with reason `no-season`, `sheet-undecided`, `sheet-ambiguous`, `sheet-superseded`, `unconfirmed`, `unmapped-column` or `blank-row` never become `refused-row` items.
5. **Digits are assigned last, in one pass, over the finished action list:** the first five actions whose `control` is not `'select'` take `1`–`5`, in order. Nothing else carries one.
6. **An unnamed debt carries no snooze and no ignore.** D8 says a nameless debt cannot be settled and cannot be dismissed; a deferral is a dismissal with a timer. Its only actions are `name-debt` and `open-source`.

```ts
/**
 * Ruling 1. The tab is derived, never stored, so the badge and the tab strip
 * cannot drift apart.
 */
export function tabOf(item: InboxItem): 'decide' | 'notice' {
  return item.blocking ? 'decide' : 'notice';
}

/**
 * B2. Only blocking items are counted, so the badge never cries wolf: a
 * refused סה״כ row and a budget line whose arithmetic does not add up are
 * both true and neither is a decision, and a badge that counted them would
 * read 40 on a camp with nothing to do.

export function openDecisionCount(items: readonly InboxItem[]): number {
  return items.filter((item) => item.blocking).length;
}

/**
 * Ruling 2. Narrower than `blocking` on purpose.
 *
 * Bulk promotion waits on the three decisions `promoteAll` itself refuses or
 * skips over. It does not wait on unlinked names or nameless debts, because
 * those are *produced by* promotion: gating on them deadlocks, since the only
 * way to clear the name queue is to promote, and a new upload could never be
 * promoted while one name sat in it.
 */
export function blocksPromotion(item: InboxItem): boolean {
  switch (item.kind) {
    case 'sheet-collision':
    case 'block-undecided':
      return true;
    case 'sheet-season':
      return item.refusesWithoutSeason;
    default:
      return false;
  }
}

/** Ruling 5: digits are handed out once, at the end, over the finished list. */
function withDigits(actions: Omit<InboxAction, 'digit'>[]): InboxAction[] {
  let next = 1;
  return actions.map((action) => {
    if (action.control === 'select' || next > 5) return { ...action, digit: null };
    const digit = next as 1 | 2 | 3 | 4 | 5;
    next += 1;
    return { ...action, digit };
  });
}
```

```ts
function formatDate(date: Date): string {
  const dd = String(date.getUTCDate()).padStart(2, '0');
  const mm = String(date.getUTCMonth() + 1).padStart(2, '0');
  const yy = String(date.getUTCFullYear()).slice(-2);
  return `${dd}/${mm}/${yy}`;   // A12: slashes in tables and chips
}

/**
 * Everything the system could not settle, in one list.
 *
 * `worklist` is called once and reused by three of the seven kinds. It runs
 * `promoteBlock(..., { dryRun: true })` per confirmed block, which is where
 * W8's "computed, never stored" lives — this module must never call
 * `promoteBlock` itself, and must never pass `dryRun: false` anywhere.
 */
export async function inboxItems(db: AnyDb, input: InboxInput): Promise<InboxItem[]> {
  const { snoozed, now, recordedBy } = input;
  const seasonId = input.seasonId ?? null;

  const [rows, collisions, seasonless, flags, debts, names] = await Promise.all([
    worklist(db, recordedBy),
    collisionGroups(db),
    sheetsNeedingSeason(db),
    flaggedArithmetic(db),
    unnamedObligations(db),
    listUnlinkedNames(db),
  ]);

  const items: InboxItem[] = [];

  /** Applies Ruling 2 of this task: a deferral removes the block, not the item. */
  const settle = <T extends InboxItem>(item: T): T => {
    const until = snoozed.get(item.id) ?? null;
    if (until === null) return item;
    return {
      ...item,
      snoozedUntil: until,
      blocking: false,
      detail: `${item.detail} · נדחה על ידך עד ${formatDate(until)}`,
    };
  };

  // --- names -------------------------------------------------------------
  for (const name of names) {
    const id = `name:${name.aliasId}`;
    const suggestions = await suggestPeopleForName(db, name.alias, { seasonId });
    const top = suggestions[0] ?? null;
    const detail = top
      ? `שם מקובץ · הצעה: ${top.displayName} (${top.confidence})`
      : 'שם מקובץ · אין הצעה';

    items.push(settle<UnlinkedNameItem>({
      id, kind: 'unlinked-name', title: `״${name.alias}״`, detail,
      source: null, blocking: true, snoozedUntil: null,
      aliasId: name.aliasId, alias: name.alias, rowCount: 0, suggestions,
      actions: withDigits([
        ...suggestions.map((s) => ({
          kind: 'link-name' as const, label: `קישור ל${s.displayName}`,
          control: 'button' as const, href: null, arg: s.personId,
          writes: true, undoable: true,
        })),
        { kind: 'new-person', label: 'יצירת אדם חדש', control: 'button', href: null, arg: null, writes: true, undoable: false },
        { kind: 'ignore-name', label: 'לא אדם — התעלמות', control: 'button', href: null, arg: null, writes: true, undoable: true },
        snoozeAction(id),
        { kind: 'search-person', label: 'חיפוש אדם אחר', control: 'button', href: null, arg: null, writes: false, undoable: false },
        { kind: 'split-name', label: 'פיצול לשני שמות', control: 'button', href: null, arg: null, writes: true, undoable: false },
        SKIP,
      ]),
    }));
  }

  // --- sheets with no season --------------------------------------------
  const bySheet = new Map<string, WorklistRow[]>();
  for (const row of rows) {
    const list = bySheet.get(row.sheetId) ?? [];
    list.push(row);
    bySheet.set(row.sheetId, list);
  }

  for (const sheet of seasonless) {
    const id = `sheet-season:${sheet.id}`;
    const blocks = bySheet.get(sheet.id) ?? [];
    const refuses = blocks.some((b) => b.refusals.some((r) => r.reason === 'no-season'));
    const waiting = blocks.map((b) => ({
      blockId: b.blockId, archetype: b.archetype, rows: b.rowCount,
    }));
    const pending = waiting.reduce((sum, w) => sum + w.rows, 0);

    items.push(settle<SheetSeasonItem>({
      id, kind: 'sheet-season',
      title: `לגיליון ״${sheet.name}״ אין שנה`,
      detail: refuses
        ? 'לגיליון לא נקבעה עונה, ותקציב חייב עונה'
        : `${pending} שורות נכתבו בלי שיוך לעונה`,
      source: null, blocking: true, snoozedUntil: null,
      sheet, waiting, refusesWithoutSeason: refuses,
      actions: withDigits([
        { kind: 'set-season', label: 'בחירת עונה', control: 'select', href: null, arg: sheet.id, writes: true, undoable: true },
        snoozeAction(id),
        SKIP,
      ]),
    }));
  }

  // --- collisions --------------------------------------------------------
  for (const group of collisions) {
    const seasonKey = group.sheets[0]?.seasonId ?? 'none';
    const id = `collision:${group.name}:${seasonKey}`;
    const diff = await copyDiff(db, group.sheets.map((s) => s.id));

    const detail = group.state === 'ambiguous'
      ? 'יותר מעותק אחד של הגיליון הזה סומן כנכון'
      : diff.ok
        ? `${diff.differing} שורות שונות · חוסם קידום`
        : diff.reason;

    items.push(settle<SheetCollisionItem>({
      id, kind: 'sheet-collision',
      title: `שני עותקים של ״${group.name}״`,
      detail, source: null, blocking: true, snoozedUntil: null,
      group, diff,
      actions: withDigits([
        ...group.sheets.map((s) => ({
          kind: 'set-authority' as const,
          label: `בחירת ${s.filename} כמוסמך`,
          control: 'button' as const, href: null, arg: s.id,
          writes: true, undoable: true,
        })),
        snoozeAction(id),
        SKIP,
      ]),
    }));
  }

  // --- blocks ------------------------------------------------------------
  for (const row of rows) {
    const unmapped = row.refusals.find((r) => r.reason === 'unmapped-column');
    if (row.state !== 'unconfirmed' && !unmapped) continue;

    const id = `block:${row.blockId}`;
    const range = `${row.sheetName}!A${row.top}:${row.bottom}`;
    items.push(settle<BlockUndecidedItem>({
      id, kind: 'block-undecided',
      title: unmapped
        ? `לטבלה אין שיוך עמודות — ${row.sheetName}`
        : `״${row.sheetName}״ — אישור סיווג`,
      detail: `${range} · ${row.rowCount} שורות`,
      source: null, blocking: true, snoozedUntil: null,
      blockId: row.blockId, archetype: row.archetype, range, rows: row.rowCount,
      reason: unmapped ? 'unmapped-column' : 'unconfirmed',
      actions: withDigits([
        {
          kind: 'confirm-block', label: 'פתיחת הטבלה לאישור', control: 'link',
          href: `/imports/${row.sheetId}#block-${row.blockId}`, arg: row.blockId,
          writes: false, undoable: false,
        },
        snoozeAction(id),
        SKIP,
      ]),
    }));
  }

  // --- nameless debts ----------------------------------------------------
  for (const debt of debts) {
    const id = `debt:${debt.id}`;
    const source = debt.sourceBlockId && debt.sourceRow !== null
      ? await traceRow(db, 'obligations', debt.id)
      : null;

    // Ruling 6: no snooze, no ignore. D8 — a nameless debt cannot be settled
    // and cannot be dismissed, and a deferral is a dismissal with a timer.
    items.push({
      id, kind: 'unnamed-debt',
      title: `חוב בלי שם — ${debt.description}`,
      detail: 'אי אפשר לסגור עד שיירשם למי',
      source, blocking: true, snoozedUntil: null,
      obligation: debt,
      actions: withDigits([
        { kind: 'name-debt', label: 'רישום למי החוב', control: 'link', href: `/money/debts?peek=${debt.id}`, arg: debt.id, writes: false, undoable: false },
        { kind: 'open-source', label: 'פתיחת התא בקובץ', control: 'link', href: source ? `/imports/${source.sheetId}#row-${source.sheetRow}` : '/imports', arg: null, writes: false, undoable: false },
      ]),
    });
  }

  // --- refused rows ------------------------------------------------------
  for (const row of rows) {
    for (const refusal of row.refusals) {
      if (CARRIED_ELSEWHERE.has(refusal.reason)) continue;
      const id = `refusal:${row.blockId}:${refusal.sheetRow}:${refusal.reason}`;
      items.push({
        id, kind: 'refused-row',
        title: `${row.sheetName}!${refusal.sheetRow}`,
        detail: refusal.message,
        source: null, blocking: false, snoozedUntil: null,
        blockId: row.blockId, refusal,
        actions: withDigits([
          { kind: 'open-source', label: 'פתיחת השורה בקובץ', control: 'link', href: `/imports/${row.sheetId}#row-${refusal.sheetRow}`, arg: null, writes: false, undoable: false },
        ]),
      });
    }
  }

  // --- arithmetic flags --------------------------------------------------
  for (const flag of flags) {
    items.push({
      id: `arith:${flag.line.id}`, kind: 'arithmetic-flag',
      title: flag.line.label,
      detail: `${flag.seasonName} · כמות × מחיר ליחידה אינו שווה לסה״כ`,
      source: null, blocking: false, snoozedUntil: null,
      seasonName: flag.seasonName, line: flag.line,
      actions: withDigits([
        { kind: 'open-source', label: 'פתיחת שורת התקציב', control: 'link', href: '/money', arg: null, writes: false, undoable: false },
      ]),
    });
  }

  // Decisions before information; within decisions, promotion blockers first.
  const rank = (item: InboxItem): number => {
    if (!item.blocking) return 2;
    return blocksPromotion(item) ? 0 : 1;
  };
  return items.sort((a, b) => rank(a) - rank(b));
}
```

```ts
import { and, eq, isNotNull, isNull } from 'drizzle-orm';
import type { AnyDb } from '@/lib/db-types';
import { persons, personAliases, seasons } from '@/db/schema/camp';
import { blocks, sheets, uploads } from '@/db/schema/source';
import type { InboxKind } from './items';

export interface ResolvedItem {
  id: string; kind: InboxKind; title: string; detail: string;
  decidedBy: string | null; decidedAt: Date | null;
}

const DEFAULT_LIMIT = 50;

/**
 * The טופלו tab: decisions already made.
 *
 * It reports only what the database already stamps. `person_aliases` and
 * `blocks` carry `confirmed_by` and `confirmed_at`, so a linked name, an
 * ignored name and a confirmed block each say who and when. `sheets` carries
 * no stamp, so a sheet that now has a season says so and says the date was
 * not kept. Borrowing `uploads.created_at` would put a date on screen that is
 * not the date of the decision, which is the class of lie this whole screen
 * exists to prevent.
 */
export async function resolvedItems(
  db: AnyDb, limit: number = DEFAULT_LIMIT,
): Promise<ResolvedItem[]> {
  const items: ResolvedItem[] = [];

  const aliasRows = await db
    .select({
      id: personAliases.id, alias: personAliases.alias,
      personId: personAliases.personId, displayName: persons.displayName,
      by: personAliases.confirmedBy, at: personAliases.confirmedAt,
    })
    .from(personAliases)
    .leftJoin(persons, eq(persons.id, personAliases.personId))
    .where(isNotNull(personAliases.confirmedBy));

  for (const row of aliasRows) {
    items.push({
      id: `name:${row.id}`,
      kind: 'unlinked-name',
      title: `״${row.alias}״`,
      detail: row.personId === null
        ? 'סומן כלא-אדם'
        : `קושר ל־${row.displayName ?? ''}`,
      decidedBy: row.by,
      decidedAt: row.at,
    });
  }

  const blockRows = await db
    .select({
      id: blocks.id, archetype: blocks.archetype, sheetName: sheets.name,
      by: blocks.confirmedBy, at: blocks.confirmedAt,
    })
    .from(blocks)
    .innerJoin(sheets, eq(sheets.id, blocks.sheetId))
    .where(isNotNull(blocks.confirmedAt));

  for (const row of blockRows) {
    items.push({
      id: `block:${row.id}`,
      kind: 'block-undecided',
      title: `״${row.sheetName}״ — אישור סיווג`,
      detail: `אושר כ־${row.archetype}`,
      decidedBy: row.by,
      decidedAt: row.at,
    });
  }

  const sheetRows = await db
    .select({
      id: sheets.id, name: sheets.name, seasonName: seasons.name,
      authoritative: sheets.authoritative, filename: uploads.filename,
    })
    .from(sheets)
    .innerJoin(uploads, eq(uploads.id, sheets.uploadId))
    .innerJoin(seasons, eq(seasons.id, sheets.seasonId))
    .where(isNotNull(sheets.seasonId));

  for (const row of sheetRows) {
    const chosen = row.authoritative === true ? ' · נבחר כעותק המוסמך' : '';
    items.push({
      id: `sheet-season:${row.id}`,
      kind: 'sheet-season',
      title: `לגיליון ״${row.name}״ אין שנה`,
      detail: `שויך ל־${row.seasonName}${chosen} · נקבע — התאריך לא נשמר`,
      decidedBy: null,
      decidedAt: null,
    });
  }

  items.sort((a, b) => {
    if (a.decidedAt === null && b.decidedAt === null) return 0;
    if (a.decidedAt === null) return 1;
    if (b.decidedAt === null) return -1;
    return b.decidedAt.getTime() - a.decidedAt.getTime();
  });

  return items.slice(0, limit);
}

/** The top bar's `נוקו היום`. An undated decision is never counted as today's. */
export function clearedToday(items: readonly ResolvedItem[], now: Date): number {
  return items.filter((item) => (
    item.decidedAt !== null
    && item.decidedAt.getUTCFullYear() === now.getUTCFullYear()
    && item.decidedAt.getUTCMonth() === now.getUTCMonth()
    && item.decidedAt.getUTCDate() === now.getUTCDate()
  )).length;
}
```

```tsx
'use client';

// A client component because a toast is a timer, a dismissal and an undo
// button — three pieces of state that exist only after a write has already
// happened, and none of which the server can hold.

import { useCallback, useEffect, useState } from 'react';
import styles from './toast.module.css';

export interface ToastMessage {
  id: string;
  text: string;
  tone: 'ok' | 'bad' | 'neutral';
  undo?: { label: string; run: () => Promise<void> };
}

const PLAIN_MS = 6000;
const UNDO_FAILED = 'לא הצלחנו לבטל את הפעולה';

export function useToasts() {
  const [toasts, setToasts] = useState<ToastMessage[]>([]);
  const push = useCallback((toast: Omit<ToastMessage, 'id'>) => {
    setToasts((all) => [...all, { ...toast, id: `t${Date.now()}${all.length}` }]);
  }, []);
  const dismiss = useCallback((id: string) => {
    setToasts((all) => all.filter((t) => t.id !== id));
  }, []);
  return { toasts, push, dismiss };
}

function Toast({ toast, onDismiss }: { toast: ToastMessage; onDismiss: (id: string) => void }) {
  const [failed, setFailed] = useState(false);
  const [busy, setBusy] = useState(false);

  // A toast that offers undo never expires. An undo that vanishes after four
  // seconds is not an undo (E2).
  useEffect(() => {
    if (toast.undo) return undefined;
    const timer = setTimeout(() => onDismiss(toast.id), PLAIN_MS);
    return () => clearTimeout(timer);
  }, [toast.id, toast.undo, onDismiss]);

  async function reverse(): Promise<void> {
    if (!toast.undo || busy) return;
    setBusy(true);
    try {
      await toast.undo.run();
      onDismiss(toast.id);
    } catch {
      // R9: no server text reaches a Hebrew screen.
      setFailed(true);
    } finally {
      setBusy(false);
    }
  }

  const tone = failed ? 'bad' : toast.tone;
  return (
    <div className={`${styles.toast} ${styles[tone]}`}>
      <span className={styles.text}>{failed ? UNDO_FAILED : toast.text}</span>
      {toast.undo && !failed && (
        <button type="button" className={styles.undo} onClick={reverse} disabled={busy}>
          {toast.undo.label}
        </button>
      )}
      <button
        type="button"
        className={styles.close}
        aria-label="סגירה"
        onClick={() => onDismiss(toast.id)}
      >
        ×
      </button>
    </div>
  );
}

export function ToastRegion({
  toasts, onDismiss,
}: { toasts: ToastMessage[]; onDismiss: (id: string) => void }) {
  return (
    <div className={styles.region} role="status" aria-live="polite">
      {toasts.map((toast) => (
        <Toast key={toast.id} toast={toast} onDismiss={onDismiss} />
      ))}
    </div>
  );
}
```

```tsx
'use client';

// A client component because a keyboard listener is a browser event: there is
// no server-rendered equivalent of "press 1 to link this name".

import { useEffect } from 'react';
import { useRouter } from 'next/navigation';

/** R10: only digits and arrows. A single-letter shortcut on a Hebrew layout
 *  is a different key on every keyboard, so there are none. */
const ALLOWED = /^Digit[1-5]$/;

function typing(target: EventTarget | null): boolean {
  if (!(target instanceof HTMLElement)) return false;
  if (target.isContentEditable) return true;
  return ['INPUT', 'TEXTAREA', 'SELECT'].includes(target.tagName);
}

export function InboxKeyboard({
  digits, prevHref, nextHref,
}: {
  digits: Record<string, string>;
  prevHref: string | null;
  nextHref: string | null;
}): null {
  const router = useRouter();

  useEffect(() => {
    function onKeyDown(event: KeyboardEvent): void {
      if (event.metaKey || event.ctrlKey || event.altKey) return;
      if (typing(event.target)) return;

      if (event.code === 'ArrowDown' && nextHref) {
        event.preventDefault();
        router.push(nextHref);
        return;
      }
      if (event.code === 'ArrowUp' && prevHref) {
        event.preventDefault();
        router.push(prevHref);
        return;
      }

      if (!ALLOWED.test(event.code)) return;
      const id = digits[event.code];
      if (!id) return;
      const button = document.getElementById(id);
      if (!(button instanceof HTMLButtonElement) && !(button instanceof HTMLAnchorElement)) return;
      event.preventDefault();
      // The keyboard presses the same control the pointer does, so the two
      // paths cannot diverge — a digit can never do something no button does.
      button.click();
    }

    window.addEventListener('keydown', onKeyDown);
    return () => window.removeEventListener('keydown', onKeyDown);
  }, [digits, prevHref, nextHref, router]);

  return null;
}
```

```tsx
  const { toasts, push: pushToast, dismiss } = useToasts();
  const [pending, startTransition] = useTransition();
  const [confirming, setConfirming] = useState<InboxAction | null>(null);

  const aliasId = itemId.startsWith('name:') ? itemId.slice('name:'.length) : itemId;

  function call(action: InboxAction): Promise<ActionResult> {
    switch (action.kind) {
      case 'link-name': return linkNameAction(aliasId, action.arg!);
      case 'new-person': return promoteNameAction(aliasId);
      case 'ignore-name': return ignoreNameAction(aliasId);
      case 'split-name': return splitNameAction(aliasId, (action.arg ?? '').split('|'));
      case 'snooze': return snoozeItemAction(itemId);
      default: return Promise.resolve({ ok: true });
    }
  }

  function reverse(action: InboxAction): (() => Promise<void>) | undefined {
    if (!action.undoable) return undefined;
    switch (action.kind) {
      case 'link-name':
      case 'ignore-name':
        return async () => { await unignoreNameAction(aliasId); router.refresh(); };
      case 'snooze':
        return async () => { await unsnoozeItemAction(itemId); router.refresh(); };
      default: return undefined;
    }
  }

  function run(action: InboxAction): void {
    setConfirming(null);
    startTransition(async () => {
      const result = await call(action);
      if (!result.ok) {
        pushToast({ text: result.error ?? 'שגיאה בשמירה', tone: 'bad' });
        return;
      }
      const undo = reverse(action);
      pushToast({
        text: receipt(action),
        tone: 'ok',
        ...(undo ? { undo: { label: 'ביטול', run: undo } } : {}),
      });
      // After each decision the next item opens by itself (D2).
      if (nextHref) router.push(nextHref);
      else router.refresh();
    });
  }

  function press(action: InboxAction): void {
    const confirmation = CONFIRMATIONS[action.kind];
    if (confirmation) setConfirming(action);
    else run(action);
  }

  const confirmation = confirming ? CONFIRMATIONS[confirming.kind]! : null;

  return (
    <div className={styles.actions}>
      {actions.map((action, index) => (
        action.control === 'link' && action.href ? (
          <Link
            key={`${action.kind}-${index}`}
            id={action.digit ? `inbox-action-${action.digit}` : undefined}
            href={action.href}
            className={styles.action}
          >
            {action.label}
            {action.digit && <span className={styles.kbd}><bdi>{action.digit}</bdi></span>}
          </Link>
        ) : (
          <button
            key={`${action.kind}-${index}`}
            id={action.digit ? `inbox-action-${action.digit}` : undefined}
            type="button"
            className={styles.action}
            disabled={pending}
            onClick={() => press(action)}
          >
            {action.label}
            {action.digit && <span className={styles.kbd}><bdi>{action.digit}</bdi></span>}
          </button>
        )
      ))}

      {confirming && confirmation && (
        <div role="dialog" aria-modal="true" className={styles.confirm}>
          <p>{confirmation.body}</p>
          <button type="button" onClick={() => run(confirming)}>{confirmation.verb}</button>
          <button type="button" onClick={() => setConfirming(null)}>ביטול</button>
        </div>
      )}

      <ToastRegion toasts={toasts} onDismiss={dismiss} />
    </div>
  );
}
```

```tsx
'use client';

// A client component because the button has three states the server cannot
// hold: pending while the promotion runs, and the result afterwards — which
// is a report a lead reads, not a new page.

import { useState, useTransition } from 'react';
import { useRouter } from 'next/navigation';
import Link from 'next/link';
import type { BulkResult } from '@/lib/import/promote/promote';
import { blocksPromotion, type InboxItem } from '@/lib/inbox/items';
import { promoteAllAction } from './actions';
import styles from './inbox.module.css';

const FAILED = 'הקידום נכשל — שום שורה לא נכתבה';

export function BulkPromote({ items }: { items: InboxItem[] }) {
  const router = useRouter();
  const [pending, startTransition] = useTransition();
  const [result, setResult] = useState<BulkResult | null>(null);
  const [error, setError] = useState<string | null>(null);

  const blockers = items.filter(blocksPromotion);
  const blocked = blockers.length > 0;

  function run(): void {
    if (pending) return;
    setError(null);
    startTransition(async () => {
      try {
        setResult(await promoteAllAction());
        router.refresh();
      } catch {
        // R9: a Postgres message never reaches a Hebrew screen.
        setError(FAILED);
      }
    });
  }

  return (
    <div className={styles.bulk}>
      <button
        type="button"
        className={styles.promote}
        // The disabling is a courtesy. promoteAllAction guards on the server
        // and promoteAll refuses a contested or seasonless block on its own;
        // a disabled button is never the enforcement (W13, W14).
        disabled={blocked || pending}
        aria-disabled={blocked || pending}
        title={blocked
          ? `ממתין להכרעה: ${blockers.map((b) => b.title).join(' · ')}`
          : undefined}
        onClick={run}
      >
        קידום כל הטבלאות
        {blocked && <span className={styles.why}> — חסום עד שההחלטות ייסגרו</span>}
      </button>

      <div role="status" aria-live="polite" className={styles.bulkResult}>
        {error && <span className={styles.bad}>{error}</span>}
        {result && !error && (
          <span>
            נכתבו <bdi>{result.writtenCount}</bdi> שורות ·{' '}
            <Link href="/inbox?tab=notice&kind=refusals">
              <bdi>{result.refusedCount}</bdi> סורבו
            </Link>
            {result.deletedCount > 0 && (
              <> · <bdi>{result.deletedCount}</bdi> שורות שהוסרו כי הטבלה כבר לא מפיקה אותן</>
            )}
          </span>
        )}
      </div>
    </div>
  );
}
```
